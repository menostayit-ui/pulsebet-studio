## Reporting a Vulnerability

We take the security and privacy of PulseBet Studio seriously. Since this is an air-gapped, local-first application designed to run on `127.0.0.1`, risks are primarily related to upstream data parsing and local WebSocket integrity.

If you discover a security vulnerability or potential exploit:

1. **Do not create a public issue.**
2. Send a report via GitHub Security Advisories or contact the repository maintainers through GitHub direct communication.
3. Include detailed steps to reproduce the vulnerability.

We appreciate responsible disclosure and will investigate and patch verified issues promptly.
